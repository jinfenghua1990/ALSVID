# ALSVID Admin Operation System V1.0

> 本文由 `docs/ALSVID_ADMIN_IA.md` 作为详细 IA 基准；本文件保留 Admin 的定位与业务范围。

## 定位

ALSVID Admin 是内部运营后台，不是商城系统，不替代 Shopify，也不是传统 ERP。官网、商城、Shopify 前台与客户公开门户保持独立。

## 交互骨架

- 顶部固定 ALSVID 品牌与一级导航；
- 点击一级模块后，左侧纵向显示该模块的详细二级菜单，右侧为工作区；
- 不使用永久固定的传统左侧一级菜单；
- 首页工作台聚焦运营概览、待办、异常与关键业务数据；
- 使用共享 `AppShell`，移动端将导航收纳为菜单。

## 一级导航

工作台、产品、订单、生产、库存、经销商、客户、售后、供应链、数据、设置。

## 业务范围

- 产品：平台、型号、版本、SKU、BOM、零部件、技术资料、工程文件；
- 订单：B2B、销售、生产需求、配件与售后订单，以及履约状态；
- 生产：计划、任务、装配、QC、VIN、序列号、出厂与追溯；
- 库存：成品、半成品、零件、仓库、出入库、调拨与预警；
- 经销商：档案、区域、授权等级、采购与销售关系；
- 客户：档案、车辆绑定、购买、保修与服务记录；
- 售后：VIN 查询、保修、维修工单、配件申请、知识库与服务统计；
- 供应链：供应商、采购、来料检测、评价与成本分析；
- 数据：销售、生产、库存、售后与经销商分析；
- 设置：用户、角色权限、审计、集成与环境。

车辆全生命周期是生产、客户与售后共用的业务对象，不单独形成一级导航。Admin 不复制 Shopify/WMS 的完整能力，页面无真实业务事实时保持明确空状态。
