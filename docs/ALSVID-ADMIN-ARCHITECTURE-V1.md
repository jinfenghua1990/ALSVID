# ALSVID Admin Operation System V1.0

## 定位

ALSVID Admin 是内部运营后台，不是商城系统，不替代 Shopify，也不是传统 ERP。

该系统服务于 ALSVID 内部团队，用于管理产品、订单、生产、库存、经销商、客户、售后和供应链业务。

## 核心原则

- 后台与商城系统分离；
- 不复制 Shopify/WMS 等外部系统完整能力；
- 以业务流程和长期业务数据为核心；
- 保持现代化后台体验，避免传统 ERP 风格；
- 产品、车辆、VIN、售后数据形成长期资产。
