# ALSVID 官方网站：整车中心与配件中心

状态：待 PR 验证 / 未发布。正式域名：`www.alsvidbike.com`。日期：2026-10-21。

## 一、路线与信息架构

- 首页主导航「产品」→ `/{locale}/bikes`，保留 FC1/FC2 直接入口。
- 首页主导航「配件」→ `/{locale}/accessories`。
- 共同支持 zh / en / de；不以 Shopify 或 `shop.alsvidbike.com` 为跳转前提。
- 网站整体视觉：克制高级、品牌视觉优先、移动端完整、允许已确认产品实拍，不把概念素材冒充真实 SKU。

## 二、页面结构

整车中心：品牌首屏 → FC/CT/FT/GT 平台 → 平台筛选 → 已存在的 FC1/FC2 型号入口 → 选车/状态导览。FC1 沿用邮件预约咨询，FC2 沿用现有新品详情。CT/FT/GT 保持概念探索，暂无经审核的商品信息时展示明确空态。不可编造产品规格、库存、价格或完成购买的承诺。

配件中心：品牌首屏 → 前篮/后货架/挡泥板/灯具/零部件分类 → 分类筛选 → 现有设计概念详情 → 车型兼容规则说明。实际车型适配必须按 Platform / Model / Variant / SKU / BOM Revision / Vehicle 等真实数据验明，不得仅用前端选择按钮宣称兼容。页面类目视觉目前是抽象插画/占位，不是配件商品摄影图。

## 三、自建商城与支付的后续接入

- **Product**：平台/车型/版本/SKU/确认的配件关系，是商品内容及兼容事实来源。
- **Commerce**：选择商品、购物车、结账编排、官网交易订单。
- **Inventory**：可售量和预留必须根据权威库存与账本确认。
- **Finance + Integrations**：核实 PSP 支付结果、退款、结算与事件签名；支付服务商仍待商户主体审核。
- **WMS**：收发仓库实物。
- **My ALSVID**：经合法授权后查询个人的真实订单、车辆和售后。
- 实付上线前必须通过 [ADR 0005](adr/0005-alsvid-owned-storefront-and-third-party-payments.md) 的全部门槛。不提前提供真实下单/收款。

## 四、本 PR 验收

1. `/zh/bikes`, `/de/bikes`, `/en/bikes` 返回 200，导航链接指向独立目录页；FC1/FC2 可进入现有详情。
2. `/zh/accessories`, `/de/accessories`, `/en/accessories` 返回 200；5 个配件类别、分类切换与概念详情可访问。
3. 桌面与移动端无水平溢出；语言切换保留目录路径；SEO 规范链接与 alternate 具备相应语言版本。
4. 页面不显示虚构价格、库存、车型适配结论，也不提供未批准的支付入口。
5. CI 类型检查、架构检查、浏览器基础验收，以及合并后以准确 commit 和生产地址做最终验证。

注意：这不是商城支付、Admin 商品管理 API、真实库存或在线购物车的完工声明。
