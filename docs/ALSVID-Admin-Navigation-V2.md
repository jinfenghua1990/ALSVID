# ALSVID Admin 顶部导航架构 V2

版本：V2
定位：ALSVID 公司内部运营中枢

## 顶部一级导航

```
工作台 | 产品 | 订单 | 生产 | 库存 | 经销商 | 客户/车主 | 售后 | 供应链 | 数据 | 设置
```

右侧快捷入口：

```
官方首页 | 经销商采购 | 我的车库
```

## 系统边界

ALSVID Admin 负责内部运营管理。

三个快捷入口对应独立系统：
- 官方首页（ALSVID WWW）：品牌官网和商城前端
- 经销商采购（ALSVID Dealer Portal）：经销商B2B业务
- 我的车库（My ALSVID）：车主生命周期服务

## 模块定位

### 工作台
运营驾驶舱：待处理事项、异常、生产状态、库存风险、售后提醒。

### 产品
产品资产中心：产品平台、型号、BOM、零件结构、工程资料、配件、生命周期。

### 订单
区分：B2C订单、B2B经销商订单、生产需求订单。

### 生产
生产计划、工单、工序、质量、VIN管理。

### 库存
成品、零件、仓库、调拨、预警。

### 经销商
经销商档案、授权区域、合作等级、采购记录、售后能力。

### 客户/车主
Customer + Vehicle + VIN：客户信息、车辆绑定、购买记录、服务历史。

### 售后
保修、维修工单、配件申请、服务记录。

### 供应链
供应商、采购、物料、质量、成本、交付。

### 数据
销售、生产、库存、售后经营分析。

### 设置
用户、权限、角色、安全、系统配置。

## 开发原则

1. 不做传统ERP堆叠，保持现代运营系统设计。
2. 产品以生命周期资产管理为核心。
3. 客户以车辆生命周期为核心。
4. Admin、WWW、Dealer Portal、My ALSVID保持边界清晰。
