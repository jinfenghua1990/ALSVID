# ALSVID WWW 首页导航验收记录（2026-10-20）

## 确认设计

- 正式品牌 WWW：`https://www.alsvidbike.com`。
- 桌面端顶部深海军蓝色 `#151C2B`，导航文字 18px；较窄桌面其余导航转入折叠菜单。**手机端 760px 及以下，顶部固定栏的第二行始终直接显示 FC1「预约」与 FC2「新品」两个可点击的车型快捷入口，无须先打开菜单。** 其他导航保留在折叠菜单中。
- 导航顺序：**FC1 [预约] → FC2 [新品] → 产品 → 配件 → 全球经销商 → 品牌故事**，右侧保留车主中心和语言切换。
- **FC1「预约」绿色**：`#B8E986`，深色字 `#17241A`。
- **FC2「新品」红色**：`#E6534B`，白色字 `#FFFFFF`。
- 徽标与车型名称同行，尺寸相同，保持键盘可访问；颜色仅表达阶段，不自动代表可支付、已确认库存或订单承诺。
- FC1 和 FC2 各自进入 `/{locale}/explore/fc1`、`/{locale}/explore/fc2`。
- 「产品」进入本页 `#platforms`，「配件」是独立一级导航项目，进入本页配件展示 `#accessories`；不是新增一个无数据的商城或结账页。
- 「品牌故事」打开现有 `/{locale}/explore/about-story`。
- 三语：中文、英文、德文都具有相同导航层级；FC1 标签分别是「预约」/「RESERVE」/「ANFRAGEN」。付费预订尚未开放，按钮与标签不应暗示付款可用。
- 首页导航和 FC1 详情页内的章节导航属于不同结构，不擅自互相替换。FC1 详情页仍保持邮件预约阶段。

## 检查与发布

`scripts/official-browser-smoke.mjs` 在 1440px 和 390px 宽度下按 zh / en / de 共 6 组检查首页导航数量、顺序、真实链接、徽标颜色、桌面字号、手机顶部车型快捷入口持续可见、顶部不遮挡 KV 标题以及横向溢出，保留原有首屏交互检查。

修改经 GitHub CI 和浏览器预览验收后进入当前 WWW-only 发布流程；后台域名证书、邮件 DNS 与支付系统独立办理。本记录仅表示代码和验收规范，不等同于部署已完成。
