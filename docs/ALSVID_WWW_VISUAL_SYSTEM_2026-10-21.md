# ALSVID WWW · 三语言统一视觉规范

范围：\`www.alsvidbike.com/zh\`、\`/de\`、\`/en\` 的公开网站。
管理后台 ALSVID Admin、Dealer Portal、My ALSVID 采用各自业务界面，不照搬官网首屏。

## 唯一共同设计来源
- 官网首页的 ALSVID 图文标识、深色石墨色导航、70px 桌面高度、地球图标语言菜单；
  任何新 WWW 页面均使用 \`PublicSiteHeader\`，不得复制一份私有 Header。
- FC1、FC2、产品、配件、全球经销商、车主入口及品牌故事共用主导航，
  当前栏目使用 \`aria-current\`；手机端统一使用响应式菜单。
- 语言切换通过唯一 \`LanguageSwitcher\`：中文 / Deutsch / English，
  保留当前页面路径、查询参数和锚点，并记录用户显式选择。
- 业务二级目录（FC1 参数、经销商申请、售后网点）保留各自功能，不改造为全站无关的同一个首屏。

## 设计元素
- 字体：Inter / Noto Sans SC / Arial；正常文本为石墨色 \`#121619\`。
- 导航：\`rgba(9,13,16,.97)\`，白色文字，细分割线，宽度由统一组件控制。
- 卡片：允许根据功能布局，但使用简洁 12px 圆角和适当留白，不加入多余图标。
- 首页 KV 的主要按钮语言延伸到其他公开页面：4px 圆角、细描边、
  \`#acd132\` 从左往右填充作为悬停反馈，不在按钮后面放重复的斜向箭头字形。
- 完全禁止把斜向箭头字形 \`↗\` / \`↘\` 当作导航、文字 CTA、卡片的默认尾缀；
  可以保留具有真实功能的方向图标（轮播、返回、滚动提示）和首页特定动效。

## 校验
- \`node --test scripts/www-visual-consistency.test.mjs\` 静态检查所有界面和三语目录。
- \`scripts/dealer-browser-smoke.mjs\` 测试德语、英语、中文下的首页、
  车型、配件、FC1/FC2、合作申请及网点页面，确认共享导航、语言切换、无横向溢出。
- 此规范是公开 WWW 的视觉及交互规范，不更改经销商或售后后台的数据权限。

## 发布
公共网站发布仍必须遵守完整生产发布与 API/数据库迁移门禁。
经销商合作申请依赖 \`0032_dealer_partnership_intake.sql\`，
表单外观更新并不等于生产 API 和数据库已完成部署。

## 自行车列表页悬浮型号导航
- zh/de/en 的自行车列表页采用与 ALSVID 首页一致的石墨深色顶部浮动导航，仅滚过车型列表首屏后出现。桌面显示 ALSVID 和型号名称，手机端只保留 FC1、FC2，且不遮挡首屏。
- 仅将有真实详情页的 FC1、FC2 用于快速导航。FC、CT、FT、GT 为技术平台，CT/FT/GT 未公布具体型号时绝不补造产品，过滤这些平台时隐藏型号快速导航。
- 车型展示上下排成独立篇章，锚点为 model-fc1 / model-fc2，滚动时激活对应型号，点击时正常跳转并保存 URL 哈希；滚动定位避开顶部浮动栏。
- 浏览器验收覆盖 zh/de/en、桌面/手机/320px、首屏隐藏、点击 FC2、自动高亮、无未发布产品捷径、无横向溢出；独立站 Admin、Dealer Portal 仍遵循各自视觉系统。
