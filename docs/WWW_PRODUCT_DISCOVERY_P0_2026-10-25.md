# ALSVID WWW 产品中心 P0 — 车型发现与可信对比

日期：2026-10-25

## 需求范围

参考成熟电助力自行车品牌的产品中心使用体验，借鉴筛选与选车型功能，不复制第三方素材或文案。本次保持 ALSVID 官网视觉规范与已有导航结构。

- 官网 `/{locale}/bikes`（zh/en/de）新增车型关键词搜索、公开展示审核状态筛选（全部 / 已审核展示 / 车型预览）。
- 车型卡片升级：官方或预览状态、型号名称、详情入口、平台、可信状态说明。
- FC1 支持样车绿色和黑/蓝/银 **设计提案色卡**；切换色卡不会修改原始实拍图片，也不表示正式 SKU 或库存。详情继续保留已有颜色模拟工具。
- 同页可选择最多三款车型并排比较：型号、平台、展示状态、已知参考信息与颜色数据。无核验参数的车型显示“尚未公开”而非捏造数字。
- 保留现有 FC/CT/FT/GT 平台路由筛选、横向吸顶分类栏、左侧页面内车型索引、整车/配件合并页面及现有 FC1/FC2/L7/L8 路由。
- 空搜索结果可清除筛选；移动端按钮可触摸、表格可横向滚动；`prefers-reduced-motion` 不强制动画。

## 已知数据与限制

- FC1 参考车为 20 英寸碳纤维折叠参考样车；所有量产和性能数据仍需工厂审核。
- `reviewed` 标志仅来源于经过审核的公开目录 `/v1/product/public/catalog`，不可据此声称实物现货或在线出售。
- FC2、L7、L8 仅展示已有实际图片、车型入口和公布状态，未接入的 SKU、价格、库存、续航及配置字段不作猜测。
- 本次是前端 P0 的 **车型选择与对比体验**，不含 Himiway 式全面价格/续航筛选（真实规格源尚不可用），不含真实下单、支付或第三方仓库接口。

## 必须验证

- TypeScript 构建、现有架构门禁、CI；三语桌面/移动端浏览器预览。
- 默认四张车型卡与左侧目录可见、无横向溢出；GT 平台不虚构车型。
- 搜索与清空、色卡选择且照片保持不变、增加/移除车型对比、响应式比较表格。
- 未通过 CI / 未部署前不能标记线上已完成。
