# ALSVID 官网商城架构规划

## 一、定位

ALSVID 官网不是单纯企业展示网站，而是品牌官网 + Shopify 商城融合体系。

目标：

- 展示品牌价值
- 展示产品体系
- 支持消费者购买
- 建立车主会员体系
- 连接后台运营系统

## 二、官网整体结构

```
ALSVID 官网商城
        |
        |-- 消费者浏览与购买
        |
        |-- 会员体系（My ALSVID）
        |
        |-- 经销商合作入口
        |
        |-- 后台数据连接
```

## 四、菜单说明

### 1. 自行车

产品核心入口：

- FC系列：碳纤维折叠
- CT系列：城市通勤
- FT系列：胖胎越野
- GT系列：长途旅行

包含：

- 产品介绍
- 技术参数
- 图片视频
- 在线购买

### 2. 配件

独立产品生态：

- 车身配件
- 骑行装备
- 升级套件
- 维修零件

### 3. 服务

车主服务入口：

- 车辆注册
- 我的 ALSVID
- 保修服务
- 维修支持
- 用户手册
- 服务网点
- 联系我们

说明：

车主会员体系属于公开用户系统，但核心数据连接 ALSVID 内部运营后台。

### 4. 关于我们

整合品牌内容：

- 品牌故事
- 设计理念
- 工程技术
- 制造工艺
- 新闻动态

不单独设置“技术”和“探索”一级菜单，避免导航过多。

### 5. 经销商合作

商业合作入口：

- 成为经销商
- 经销商申请
- 经销商登录

经销商属于商业客户体系，不属于普通消费者会员。

## 五、Shopify关系

ALSVID 官网商城采用 Shopify 作为交易基础。

流程：

```
用户
 ↓
ALSVID官网
 ↓
产品页面
 ↓
购买
 ↓
Shopify订单
```

## 六、会员体系

My ALSVID 面向购买用户开放。

用户可以查看：

- 我的车辆
- 车辆注册
- 保修状态
- 维修记录
- 服务历史
- 配件推荐

后台管理：

```
用户数据
 ↓
ALSVID运营后台
 ↓
CRM / 售后 / 车辆档案
```

## 七、系统边界

消费者：

```
官网商城 Shopify
```

经销商：

```
Dealer Portal
```

内部员工：

```
ALSVID运营后台
```

三者独立，通过接口连接。

## 八、设计原则

- 官网保持国际品牌简洁风格
- 不展示ERP、生产、库存等内部信息
- 产品体验优先
- 购买路径清晰
- 服务体系长期沉淀用户资产
