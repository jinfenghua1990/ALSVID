## Changes
Five linked feature cards introduce the product narrative with a clear visual hierarchy:
one large unfolded-riding hero, one separate folded-bike card, and three supporting
cards for the low-step frame, suspension/braking, and rear-hub assistance/seatpost
battery. Every card contains exactly one existing FC1 product image; no image collage
is used. The hero and fold card use the existing side and folded cutouts, while the
supporting cards use the existing three-quarter, front-suspension and drivetrain
photographs. The sticky chapter navigation and all later sections remain available.

The overview now uses a graphite/navy surface, restrained slate-blue gradients,
cool cyan accents, fine technical grid lines and more deliberate type scale and
spacing. Desktop uses a wide primary hero across two columns with four distinct
secondary cards in the supporting layout; tablet and mobile reflow without horizontal
overflow. Copy is available in Chinese, English and German. Product photography remains
from the repository's existing FC1 reference assets: no AI-generated bicycle, altered
frame geometry, synthetic folding state, battery extraction animation, or unverified
specification is introduced.

IntersectionObserver reveals headings; a passive, animation-frame scheduled listener
updates reading progress and gentle desktop hero travel. Content is visible without
JavaScript. Reduced motion is respected, including preference changes while the page
is open. Original interactive components are reused.
