> **2026-10-21 恢复说明：** 本文最初在 PR #171 合并，后被 PR #174 的文件变更删除，现恢复原有的 10 模块优化基准以避免规范丢失。本文的表格样例、功能描述及流程是**设计要求**，不表示已实际保存数据库或在正式环境验收。最新执行顺序及真实状态见 [ALSVID_ADMIN_EXECUTION_PRIORITY_2026-10-21.md](ALSVID_ADMIN_EXECUTION_PRIORITY_2026-10-21.md)。

## 定位

ALSVID Admin 定位为公司内部运营中枢，不做传统 ERP，不做商城后台。

核心业务链：

产品 → 型号 → BOM → 生产 → 库存 → 订单 → VIN → 交付 → 车主 → 售后

保持现有 UI 风格：

- Apple / Tesla / Linear 风格
- 简洁卡片布局
- 不推翻视觉设计
- 优先优化业务逻辑、字段和模块关联

---

# 模块优化原则

所有模块保持当前 UI，仅调整：

1. 菜单结构
2. 列表字段
3. 详情页面
4. 数据关联

---

# 产品中心

产品中心升级为产品生命周期管理中心。

型号列表增加：

型号 | 平台 | 版本 | 状态 | 当前阶段 | 关联BOM

示例：

FC1 | FC | Standard | 量产 | 生产中 | BOM V1.2
FC1 Pro | FC | PRO | 量产 | 生产中 | BOM V2.0
GT1 | GT | Standard | 规划 | 研发阶段 | 待建立

建立：型号 → BOM → 生产 → 库存 → 订单链路。

---

# 订单中心

升级为销售订单与履约生命周期管理。

订单列表增加：

订单号、订单类型、客户/经销商、车型、VIN状态、金额、生产状态、交付状态。

订单状态拆分：

- 订单状态
- 生产状态
- 物流状态
- 交付状态

订单详情关联：产品、BOM、生产计划、VIN、物流、车主。

---

# 生产中心

升级为制造生命周期管理。

生产计划增加：

计划编号、型号、BOM版本、数量、生产线、VIN范围、状态。

流程：

型号 → BOM → 生产计划 → 工单 → 装配 → 质检 → VIN → 入库。

VIN升级为车辆数字档案。

---

# 库存中心

升级为整车、零件、半成品库存管理。

增加库存状态：

- 可销售库存
- 已预留库存
- 待交付库存
- 质检库存
- 维修库存

整车库存关联型号、SKU、VIN、订单。

---

# 经销商中心

定位为渠道运营管理。

增加：

- B2B订单
- 经销商库存
- 销售表现
- 售后能力
- 培训认证

列表增加库存、采购金额、销售额、售后能力。

---

# 客户/车主中心

定位为车辆资产生命周期管理。

取消传统会员等级。

使用：普通车主、认证车主、VIP车主、企业客户、车队客户。

客户数据增加VIN、车辆数量、车型、保修状态、服务记录。

---

# 售后中心

定位为车辆生命周期服务中心。

VIN详情显示：

- 型号
- 配置
- BOM版本
- 生产日期
- 车主
- 保修状态
- 维修记录
- 配件记录

---

# 供应链中心

定位为供应商生态与采购管理。

供应商列表增加：

供应商、供应类别、等级、负责零件、交付评分、质量评分。

建立：供应商 → 零件 → BOM → 产品 → 生产关联。

---

# 数据中心

定位为企业运营驾驶舱。

核心指标：

销售订单、生产数量、库存车辆、待交付车辆、活跃经销商、售后工单。

---

# 设置中心

增加：

- 组织架构
- 部门/工厂/仓库管理
- 角色权限
- 数据权限
- 安全登录
- 审计日志

---

# 执行顺序

第一阶段：菜单和页面结构调整。

第二阶段：列表字段优化。

第三阶段：详情页面建设。

第四阶段：模块数据关联。
