# ALSVID Admin Operation System V1.0

## 定位

ALSVID 后台运营系统（Admin Operation System）用于内部运营管理。

本系统与官网商城、Shopify 前台、客户公开门户分离。

核心服务对象：

- 管理层
- 销售团队
- 生产团队
- 仓库团队
- 售后团队
- 供应链团队

## 一级导航

```
ALSVID Admin

├── 工作台 Dashboard
```

## 架构原则

1. 不做传统ERP界面。
2. 后台以业务流程为核心，而不是部门表单堆叠。
3. 产品、车辆VIN、生产、售后形成生命周期闭环。
4. 保留未来扩展能力：数字孪生、AI分析、服务生态。
5. 商城系统与内部运营后台保持边界清晰。
