# 第一部分：产品中心优化建议

## 产品中心整体定位

### 当前：
产品中心类似产品目录管理。

### 修改：
调整为：

> ALSVID 产品生命周期管理中心。

负责管理：

```
产品平台
↓
型号
↓
配置
↓
SKU
↓
BOM
↓
工程文件
↓
生产
```

---

## 1. 产品系列卡片优化

### 当前页面：
显示：

```
FC Series
Folding Carbon 平台
型号：FC1 · FC1 Pro
```

```
CT Series
City Touring 平台
型号：CT1
```

### 修改：
卡片名称由：

```
FC Series
```

修改为：

```
FC Platform
```

示例：

```
FC Platform
折叠碳纤平台
型号：
FC1
FC1 Pro
当前阶段：
2个量产型号
BOM：
V1.2 / V2.0
```

### 修改原因：
Series 更偏销售分类。
Platform 更符合制造企业产品架构。
ALSVID 后续可能：

```
FC Platform
├ FC1
├ FC1 Pro
├ FC2
└ FC Carbon
```

所以这里应该展示平台，而不是销售系列。

### 业务关联：
连接：

```
产品平台
↓
型号管理
↓
BOM
↓
生产计划
```

## 2. 型号列表字段优化

### 当前页面：
字段：

| 型号 | 平台 | 版本 | 状态 |
|---|---|---|---|
| FC1 | FC | Standard | 在售 |
| FC1 Pro | FC | PRO | 在售 |
| CT1 | CT | Standard | 在售 |
| GT1 | GT | Standard | 规划中 |

增加字段：

| 型号 | 平台 | 版本 | 状态 | 当前阶段 | 关联BOM |

```

↓

↓

↓
```
