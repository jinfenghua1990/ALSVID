# ALSVID Admin

status: active
owner: ALSVID
last_reviewed: 2026-10-16

后台用于管理产品、订单、客户、经销商、售后和内容等业务数据。权限按角色最小化，运行数据不复制到知识库。

内部运营设计归 Ardot，优先可读状态、筛选、批量操作和高效表单。Supplier 档案、采购批准、生产/QC 等内部职责留在 Admin；供应商外部自助界面由 Supplier Portal 承接。设计导入/fixture 不表示真实业务写入已完成。

来源与执行：[门户实施台账](../../docs/PORTAL_DELIVERY_PLAN_2026-10-16.md)。
