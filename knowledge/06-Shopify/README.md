# Shopify

存放 Shopify 商品字段、内容发布、客服标签和自动化规则。商品事实先在 `02-Products/` 确认，再同步到这里。

门户协作方向（2026-10-16）：Shopify 是 B2C/B2B 买方交易与客户账户来源；ALSVID Product/Engineering 管内部 SKU/BOM，Vehicle/Service 管车辆与售后，Procurement 管上游供应商协同 PO。不要将 Shopify 后台 Supplier/PO 功能推导成 ALSVID Supplier Portal 已具备。

Dealer 的 Shopify Company/Location/Contact、客户账户及套餐权限须在实际店铺验证；My 的 Shopify 登录需完成身份回调和 ALSVID 资源授权。当前代码缺口和带日期的官方资料统一维护在[门户实施台账](../../docs/PORTAL_DELIVERY_PLAN_2026-10-16.md)，不在知识库复制运行订单、账号或凭据。
